# 학생 흐름 구현 및 아침 확인 · 2026-10-13 KST

## 현재 상태

교사용 `aiPreview`의 실제 인터뷰·기사 생성은 사용자가 성공 확인했습니다. 새 학생 흐름은 코드와 로컬 에뮬레이터 검증 단계입니다. 새 서버·화면은 이 작업 환경에 배포 인증이 없어 아직 운영에 배포하지 않았습니다. 기존 GitHub Pages 파일과 운영 학생 데이터는 변경하지 않았습니다.

## 구현

- 새 callable `studentApi`: 교사 Google 인증, 승인 확인, 학급 생성, QR 참여, 번호 중복 방지.
- 이름 대신 별명을 입력합니다. 이름·반·번호는 OpenAI 요청에 포함하지 않습니다. 답변에 스스로 개인정보를 넣는 것까지 완전히 익명화하지는 못합니다.
- 학생 답변을 Firestore에 먼저 저장하고, 후속 질문은 별도 생성합니다. 생성 실패 시 기록을 유지하고 다음 질문 버튼으로 복구합니다.
- 첫 질문도 실제 AI가 생성합니다. 완료된 단계는 중복 생성하지 않습니다. 세션별 생성 잠금·90초 임대·단계당 최대 3회 시도·답변 버전 검사를 적용했습니다.
- 원본 기사는 한 번 생성하여 보존합니다. 수정본 자동 저장(650ms), 수동 저장, 제출 시 최종본 불변 처리, 교사 원본/수정본/제출본 비교.
- 전송 전 답변과 미저장 기사는 현재 탭에 임시 보관합니다. 보낸 답변·저장한 기사는 서버에 보관합니다. 공유 기기에서는 활동 종료를 사용합니다.
- 교사 발급 10분짜리 일회용 기기 변경 링크. 사용 시 이전 기기의 세션 권한과 연결을 회수하며, 다른 학생 세션을 덮어쓰지 않습니다.
- `invoker:'public'`을 소스에 명시해 OPTIONS 403 문제 재발을 예방합니다. Firebase 로그인·교사/소유자 검사·App Check는 유지합니다.
- 새 `live*` 컬렉션은 클라이언트 직접 접근을 전부 거절하는 기존 기본 규칙을 사용합니다. 서버 API에서만 읽고 씁니다.

## AI 모델·프롬프트 설정 추가

새 수업 만들기와 학급 상세에서 모델·말투·인터뷰 추가 지침·기사 추가 지침을 저장합니다. 교사 AI 시험 화면(`/?ai-test`)에도 같은 설정을 제공합니다. 설정은 새로 참여하는 학생부터 적용되며 기존 세션은 시작 당시 설정을 보존합니다. 공통 안전 프롬프트를 화면에서 읽을 수 있고, 개인정보·사실성·출력 형식 규칙은 서버가 유지합니다. 모델과 프롬프트 버전은 생성 작업 기록에 남습니다.

기본 GPT-4.1 mini(2025-04-14)를 유지하며 GPT-5.4 mini(2026-03-17)를 추가했습니다. 후자는 reasoning.effort=none을 사용합니다. 각각 입력/출력 100만 토큰당 $0.40/$1.60, $0.75/$4.50 기준입니다. 학생 API는 선택 모델 단가로 비용을 선예약하며 기존 일 $5 예약 상한을 유지합니다. 이 상한은 Firebase 비용이나 별도 교사 시험 API 비용을 포함하지 않습니다. 요금 기준 변경 시 shared/ai-settings.ts 단가도 갱신해야 합니다.

GPT-5.4 mini의 계정 사용 가능 여부, 실제 과금·속도·한국어 질문 품질은 아직 검증하지 않았습니다. 교사 시험에서 가상 답변으로 확인한 뒤 수업에 선택하세요. 더 비싼 GPT-5.6 Terra는 선택지에 추가하지 않았습니다.

공식 근거: https://developers.openai.com/api/docs/models/gpt-5.4-mini

## 아침 배포

Cloud Shell에서 이 브랜치의 최신 커밋으로 이동한 다음 프로젝트 디렉터리에서 실행합니다.

```bash
bash deploy-student-preview.sh
```

프로젝트는 `future-career-interview`로 고정합니다. 서버 비밀값은 이미 등록한 것을 재사용하며 읽거나 출력하지 않습니다. 스크립트는 **성인 교사 시험 모드**로 배포합니다. 익명 학생 참여는 닫혀 있습니다.

1. https://future-career-interview.web.app/ 에서 교사 로그인 (`0361kr@gmail.com`). 기존 교사 승인을 재사용합니다.
2. 수업을 생성하고 학급 QR의 학생 입장 체험을 엽니다.
3. 필요하면 '교사 계정으로 학생 흐름 시험' 버튼으로 같은 교사 계정에 로그인합니다. 가상 별명·번호·직업으로 입장합니다.
4. 첫 AI 질문 → 답변 3개 → 인터뷰 마치기 → 기사 생성 → 수정 → 저장 → 최종 제출.
5. 교사 작업실에서 같은 학급의 원문/AI 원본/최종본을 확인합니다.
6. 새로고침 후 이어하기와 인터넷 끊김 후 저장 재시도를 확인합니다. 태블릿 UI·Google 팝업·App Check 실제 검증도 필요합니다.

## 실제 학생 개방 전 결정

초6에는 만 13세 미만이 포함됩니다. OpenAI 공식 Under-18 안내는 만 13세 미만 또는 해당 디지털 동의 연령 미만의 개인정보 처리 전에 Zero Data Retention을 요구합니다. `store:false`와 별명 사용만으로 이 조건이 충족되지는 않습니다. 학교의 개인정보 처리 근거·보호자 절차·OpenAI 데이터 보존 설정을 확인해야 합니다.

성인 교사는 `STUDENT_AI_ENABLED=false` 상태에서도 자신이 만든 학급으로 전체 흐름을 시험할 수 있습니다. 실제 개방을 승인한 뒤 서버 설정을 변경하고 `studentApi`를 배포합니다. 이 문서는 그 승인이나 ZDR 설정이 완료됐다고 간주하지 않습니다.

운영 전 남은 사항: 실제 115명 동시 부하/태블릿 검증, 연령별 콘텐츠 필터와 위험 대화의 교사 알림 운영. 현재 90일은 **접근 만료**이며 자동 영구 삭제가 아닙니다. 운영 전에 세션·기사·복구·작업·한도 기록의 보존 기간과 자동 정리 정책을 확정해야 합니다. QR만으로 실제 학생 신원은 증명되지 않으므로 교사가 번호 선점이나 기기 변경을 확인해야 합니다.

## 속도 및 비용

- 모델: `gpt-4.1-mini-2025-04-14`. 임의로 상위 고가 모델로 바꾸지 않았습니다.
- 공식 표준 요금: 입력 100만 토큰 $0.40, 출력 $1.60 (2026-10-13 확인). 예시: 학생당 모든 요청을 합쳐 입력 20,000/출력 3,000이면 $0.0128, 115명이면 약 $1.47. 재시도·Firebase 비용·세금 제외, 실제 측정치가 아닌 가정입니다.
- 학생 API: UTC 일자당 최대 1,500회 및 보수적 토큰 추정으로 $5 상당의 예약 예산. 실패한 요청도 환불하지 않는 보수적 한도입니다. 세션당 최대 `질문수×3+3`회. 요금 변경 시 단가 갱신이 필요합니다.
- 교사 전용 aiPreview 한도(교사 30/프로젝트 100회)는 별도입니다. 학생 API의 $5 제한은 프로젝트 전체 결제 상한이나 Firebase 요금 상한이 아닙니다.
- 유료 자동 재시도 없음. 모델은 유지하고 불필요한 인사를 줄였습니다. 교사 시험 화면에는 OpenAI 응답 소요 시간을, 학생 작업 기록에는 전체 AI 단계 시간을 추가했습니다.
- 스트리밍은 아직 적용하지 않았습니다. 서버 콜드 스타트·App Check·네트워크·모델 시간이 합쳐져 느릴 수 있으나 실제 병목은 측정 전입니다. 상시 인스턴스를 켜서 유휴 요금을 발생시키지는 않았습니다.

## 검증 경계

에뮬레이터 통합 테스트는 실제 Firestore 트랜잭션을 사용하고 OpenAI만 가짜 응답으로 대체합니다. callable `.run`을 사용하므로 실제 HTTP App Check 검증/브라우저 CORS/클라우드 IAM을 검증한 것은 아닙니다. 브라우저 시각 검사와 새 학생 코드의 실제 모델 호출은 미실행입니다.


## 수업 종료 삭제 기능 추가 · 2026-10-13

학생에게는 완전 익명이라고 약속하지 않고 별명 참여로 안내합니다. 번호와 학급은 교사가 알아볼 수 있고, 자유 답변에 식별 정보가 포함될 수 있습니다. 이름·학교·연락처 등을 입력하지 않도록 안내합니다.

교사 학급 상세의 `수업 종료·자료 삭제` 버튼과 확인창으로 실행합니다. 단순 입장 마감이나 학생의 활동 종료 버튼은 삭제하지 않습니다. 서버는 먼저 학급을 삭제 중으로 잠가 읽기/입장/저장을 차단하고, 세션·기사 원본/수정본/제출본·중복 요청 응답 캐시·AI 작업 기록·복구 링크·세션별 한도 기록·현재 기기 연결·학급 QR·하위 구성원을 삭제합니다. 세션은 관련 사본 삭제 후 마지막에 지워 실패 시 재실행할 수 있습니다. 다른 학급은 유지합니다.

서버 활성 Firestore 자료를 삭제하는 기능이며 자동 시간 예약 삭제는 아닙니다. 교사가 수업 직후 실행해야 합니다. Firebase Authentication 익명 계정, 내용 없는 전역 예산/요청 빈도 카운터, 클라우드 인프라 로그·별도 백업, 다른 기기에 남은 화면/임시 입력, 인쇄·다운로드 사본, 교사 전용 AI 시험 기록, OpenAI 보존 자료까지 삭제한다고 보장하지 않습니다. 공유 기기의 학생은 활동 종료로 임시 입력을 정리하고 탭을 닫아야 합니다.

별명과 수업 후 삭제는 OpenAI의 13세 미만 개인정보 처리 시 사전 ZDR 조건을 대신하지 않습니다. 계정의 해당 설정은 확인되지 않았습니다.
