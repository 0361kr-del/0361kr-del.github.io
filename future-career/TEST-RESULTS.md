# AI 시험 오류 진단 개선 · 2026-10-13

- 사용자 보고: 교사 승인 완료, AI 요청은 일반 오류 문구로 실패. 실제 원인은 아직 미확인.
- 제공자 HTTP 오류를 고정 코드로 구분하고, 네트워크·응답 형식·미완성 출력 오류를 화면에 표시. 서버 로그는 허용된 코드만 기록하며 제공자 응답 본문·키·대화는 기록하지 않음.
- Secret 값 앞뒤 공백/줄바꿈 제거. 인증 및 App Check 검증은 유지.
- Functions 빌드, 웹 타입 검사 및 Vite 빌드 통과. 테스트 21개 통과. 로컬 기본 테스트는 임시 캐시 디렉터리 오류가 있어 `TSX_DISABLE_CACHE=1 npm test`로 실행.
- 실제 API 성공 및 수정본 배포는 미검증. Cloud Shell에서 배포 후 진단 코드 확인 필요.
